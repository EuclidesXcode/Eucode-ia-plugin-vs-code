Comandos personalizaveis
Digite / no chat para ver e usar seus comandos. Cada comando expande para um prompt salvo, opcionalmente com AUTO ou HYBRID ja ligados.
Memoria da sessao
Decisoes, preferencias e comandos aprovados ficam em .eucode/memory/session_<id>.json. Digite /lembrar <texto> no chat para gravar uma nota manualmente. O agente tambem pode salvar usando a tool memory_remember. A memoria e injetada como contexto resumido em cada rodada.
🎙 JARVIS — Modo de voz BETA
Pressione o microfone no chat e fale — o audio e transcrito localmente via Whisper no LM Studio. O agente pode responder em voz alta. Feature em BETA — reporte bugs no GitHub.
Falar respostas em voz alta (TTS) Le respostas do agente usando voz do sistema. So texto puro, ignora blocos de codigo.
Requer ffmpeg (brew install ffmpeg). A captura roda fora do webview.
Para voz masculina em PT-BR, baixe "Felipe" em Ajustes do Sistema → Acessibilidade → Conteúdo Falado → Vozes do sistema.
Escutar palavra de ativação Ouve o microfone continuamente; ao dizer a palavra, grava seu comando e envia após ~5s de pausa. Consome CPU/bateria.
Dita antes do comando. Use uma palavra que o Whisper reconheça bem.
Servidor de voz (para app mobile) Sobe um servidor HTTP local que aceita comandos do app mobile.
Expor na rede local Ative para o app mobile na mesma WiFi conectar. Sem isso, so localhost.
